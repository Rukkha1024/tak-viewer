# 화면 디자인

화면은 어두운 패널과 3D 화면으로 구성해요. 왼쪽은 파일 탐색, 가운데는 3D 화면, 오른쪽은 마커와 장치 정보를 기본으로 배치해요. 패널을 옮겨 배치를 바꿀 수 있어요. 마커는 평평한 원으로 표시하고, 선택과 재생 위치는 별도 색으로 구분해요. 실제 색과 글꼴 설정은 `tak_viewer/src/ui/theme.rs`에 있어요.

아래 OptiTrack 공개 문서의 화면과 설정을 참고했어요. 원본 그림은 이 저장소에 포함하지 않아요. Motive 화면과의 동일성은 검증하지 않았어요.
