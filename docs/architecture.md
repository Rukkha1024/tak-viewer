# 구조

`tak_core`는 TAK · TAKM 읽기, 화면에 쓸 자료 만들기, 재생과 Comment 저장을 담당해요. `tak_viewer`는 창과 명령줄, 그림 출력을 담당해요. 파일 형식은 [TAKM 문서](takm.md)에 있어요.

## 저장소와 캡처 경로

기존 상위 프로젝트의 저장소 판별은 그대로 유지해요. 독립 저장소는 추적되는 `.tak-viewer-root` 파일이 있고, 그 내용이 정확히 `tak-viewer\n`일 때만 저장소로 판별해요. 이때 입력 파일이나 현재 작업 폴더의 상위 폴더에서 저장소를 찾아요. 판별된 저장소의 `input/`은 보호해요.

- 저장소를 찾으면 기본 캡처 경로는 그 아래 `experiments/tak_captures/<시각>_<파일 이름>`이에요.
- 입력 파일과 현재 작업 폴더의 상위에서 저장소를 찾지 못하면 기본 경로는 시스템 임시 폴더의 `tak_viewer/captures/<시각>_<파일 이름>`이에요.
- `--out`으로 경로를 직접 지정하는 동작은 그대로예요. 기존 경로 검사와 보호 규칙도 그대로 적용해요.
- 자동 검사는 병렬 실행 중 환경 변수를 바꾸지 않아요.

## 데이터와 쓰기

`.takm`은 카메라 기록을 제외한 사본에 Comment를 저장해요. 현재 변환은 기존 `.takm`을 덮어쓰지 않으며, 보호된 `input/`에 만들거나 Comment를 추가하지 않아요. 그림과 JSON 출력에도 기존 경로 검사를 적용해요.

## 확인

`cargo test --workspace --locked`로 자동 검사를 실행해요. 창과 그림 출력은 별도로 확인해야 해요. 파일을 읽는 성공만으로 Motive 호환성이나 동등한 동작이 검증되는 것은 아니에요.
